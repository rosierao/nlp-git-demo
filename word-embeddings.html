    What embeddings are these? / 数据与教学说明

    Real pretrained vectors, not invented coordinates. GloVe 6B, 50 dimensions, trained on Wikipedia 2014 + Gigaword 5 (6 billion tokens). This file embeds a curated teaching subset of the original 400,000-word vocabulary. The original numeric vectors are preserved. Categories are hand-assigned display labels, not learned classes.

    How the calculation works. For a word query we rank all other included words by cosine similarity. For an analogy we calculate q = v(B) − v(A) + v(C) using the original, unnormalized 50D vectors, then rank by cosine similarity to q, excluding A, B and C. Exactly three results are shown. Scores are similarities, not probabilities. Results are restricted to the embedded subset; the full vocabulary can produce different rankings.

    The orange arrows show A → B and the same displacement from C to the computed target (◇). The dashed line links that target to the winning word: an approximation, not an exact equality. An analogy may fail; these static vectors reflect patterns and biases in their training text and assign only one vector to each word.
